# Black Friday

Les achats que gus guette pour le Black Friday, en app iPhone utilisable hors connexion.
Site statique publié avec GitHub Pages. Pour l’installer : ouvrir l’adresse du site dans Safari, puis Partager, puis « Sur l’écran d’accueil ».

La liste vient de `articles.json`. Les modifications faites dans l’app restent sur l’appareil.
